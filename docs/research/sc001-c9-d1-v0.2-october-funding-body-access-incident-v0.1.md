Status: **CONTAMINATION INCIDENT — C9 FUNDING CHANNEL ONLY / NO STRATEGY OUTCOME COMPUTED**

## 1. Trigger

C9-D1 v0.2 returned:

`C9_D1_V02_FUNDING_ARCHIVE_INTEGRITY_REVIEW`

with repeated target timestamp:

`1727740800000 = 2024-10-01T00:00:00Z`

outside the intended September source-month boundary.

A subsequent metadata-only audit showed that the D0 historical-funding metadata query returned, and D1 downloaded locally, both:

- `*-fundingrates-2024-09.zip`;
- `*-fundingrates-2024-10.zip`;

for the frozen eight-asset universe.

## 2. What the v0.2 code actually did

For each asset, v0.2:

1. accepted the full D0 file set for the September metadata query;
2. downloaded/reused every file in that set;
3. opened each ZIP;
4. iterated CSV rows for the exact target instrument;
5. parsed and validated funding-rate values and funding timestamps;
6. only after combining rows performed the source-month timestamp boundary check.

Therefore the October funding ZIP body was not merely present locally: it was opened and target funding rows were parsed.
