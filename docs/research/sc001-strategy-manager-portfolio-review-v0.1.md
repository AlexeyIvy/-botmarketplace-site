# STRATEGIC IMPLICATION

For approximately USD 1,000 starting capital, the portfolio should favor mechanisms with:
- frequent opportunities;
- short capital occupancy;
- one-sided/two-fill monetization where possible;
- broad liquid-universe applicability;
- causal public observability;
- a structural payer capable of producing more than the ordinary SC001 low-single-digit information scale.

The recent portfolio evidence argues against making rare administrative events the main engine:
- B14-A remains tied to future expiry events and a repaired prospective collection path;
- B13-B requires future launch events only;
- B15-P2 is semantically useful but event-driven and its registered P0 failed source coverage because exact-minute positive trade activity was sparse.

The next primary should therefore ask whether an **ordinary-frequency state with a structural mandatory-flow payer** can create actionable headroom before expensive execution modeling.

# CANDIDATE PORTFOLIO

## Candidate 1 — Venue-local forced-flow relative dislocation

### A. Mechanism identity

**Family:** explicit liquidation-driven venue-local relative dislocation and re-anchoring.

**Economic payer:** forced deleveraging creates non-discretionary, price-insensitive inventory transfer on one venue. If that local forced flow temporarily pushes the venue away from an independently trading same-underlying reference, arbitrage/liquidity provision can re-anchor the local price after the forced flow ends.

**Causal trigger/state:** retain the already-frozen B13-C explicit pure-side liquidation-cluster semantics as the event identity, but measure the event against a strict-coactive external same-underlying price reference rather than against the venue's own later absolute return.

**Why the effect could exist:** forced orders are not voluntary alpha-seeking orders; they can temporarily consume local liquidity while the external reference continues to represent broader price discovery.

**Nearest prior SC001 mechanisms:**
- B13-C S0: explicit liquidation burst followed by unconditional same-venue 30-second reversal;
- C8B/RB011-RB013: continuous cross-venue relative-basis measurement.

**Mechanism disposition:**  
`RELATED_BUT_MATERIALLY_DIFFERENT_ARCHITECTURE`

The defining difference is the economic object and monetization path:
- parent B13-C S0: absolute same-venue post-event reversal;
- new family: event-conditioned **venue-relative concession/premium** versus a coactive external reference, with one-sided monetization on the forced venue.

If the implementation changes only liquidation size, cluster count, cluster gap, symbol subset, entry delay or hold horizon while retaining the old same-venue reversal object, it is `SAME_MECHANISM_VARIANT` or `DISGUISED_RESCUE_REJECT`.

This family is `ADAPTIVE_DISCOVERY_GENERATED`.

### B. Opportunity economics

- qualitative frequency: **many/day** across the current 12-symbol liquidation universe;
- expected capital occupancy: seconds to tens of seconds;
- likely universe breadth: broad across liquid USDT perpetuals, subject to exact same-underlying reference qualification;
- likely liquidity quality: generally high, but temporarily degraded during the exact state being studied;
- small-capital suitability: structurally good if the relative dislocation clears taker/spread/slippage burden, because USD 1,000 is unlikely to be capacity-limited in the qualified liquid names.

Prior RB021 frequency is usable only as a state-frequency prior, not as new edge evidence.

### C. Timescale

Mechanism timescale:
- formation: sub-second to several seconds during forced-flow clustering;
- re-anchoring: expected in seconds, not minutes/hours, on liquid cross-venue instruments.

Primary S0 state clock:
- first actionable strict-coactive one-second observation after a fixed one-second reaction delay;
- no return horizon and no PnL in S0.

If S0 survives, the proposed first convergence horizon is **10 seconds**, frozen once before fresh convergence evidence. The reason is the mechanism: cross-venue liquidity/arbitrage re-anchoring should decay quickly. Extending to minutes merely to obtain more bps would violate the mechanism-timescale rule.

Latency sensitivity: **moderate-high**, but deliberately not sub-millisecond. A mechanism that disappears before the first one-second actionable observation is unsuitable for the target independent trader.

### D. Edge-to-Fill preflight

Structural fills:
- trade only the forced venue;
- external venue is a reference, not a hedge leg;
- entry + exit = **2 structural fills**.

Primary burden assumption:
- no maker rebate credit;
- calculate the exact two-fill regular-user fee floor plus spread/depth reference plus execution/model reserve before any S0 outcome;
- define the S0 gross-headroom hurdle prospectively as:

`H = max(30 bps, two_fill_structural_burden_bps + 10 bps)`

The 30 bps floor preserves the existing conservative two-fill SC001 headroom posture and prevents a weak low-single-digit state from being promoted by optimistic execution assumptions.

Spread/slippage sensitivity is highest during liquidation pressure and must therefore be treated as a reason to raise, not lower, the hurdle.

### E. Cheapest falsification test

Use fresh post-freeze evidence only.

For every eligible liquidation cluster:
1. use strict-coactive one-second Bybit/OKX public trade prices with no carry-forward;
2. define
   `raw_basis_bps(t) = 10000 * ln(P_Bybit(t) / P_OKX(t))`;
3. define the causal local basis reference as the median of strict-coactive raw basis over the prior 300 wall-clock seconds, current second excluded, minimum 120 valid observations;
4. define
   `relative_dev_bps(t) = raw_basis_bps(t) - local_basis_ref_bps(t)`;
5. pressure sign:
   - `LONG_LIQUIDATED -> -1`;
   - `SHORT_LIQUIDATED -> +1`;
6. define
   `forced_flow_dislocation_bps = pressure_sign * relative_dev_bps(t)`;
7. observation clock:
   first strict-coactive one-second bucket whose start is at least 1 second after cluster end and less than 2 seconds after cluster end. If unavailable, the event is source/latency-ineligible.

S0 opens **no later price**, no convergence return, no L2, no execution simulation and no PnL.

Fresh window:
- first seven complete UTC days beginning after the commit that freezes the candidate fingerprint and S0 protocol.

Minimum sample/source gate:
- at least 300 valid clusters;
- at least 8 of the 12 frozen symbols represented;
- at least 5 distinct UTC days represented;
- all event windows pass the existing source-gap censoring rule;
- cross-venue economic identity is pre-qualified before any ratio is calculated.

S0 `SURVIVE_HEADROOM` only if all are true:
- pooled median `forced_flow_dislocation_bps >= H`;
- at least 6 frozen symbols have positive median forced-flow dislocation;
- at least 5 of the 7 UTC-day medians are positive.

If the sample/source gate passes but any headroom/breadth gate fails:

`REJECT_FORCED_FLOW_RELATIVE_HEADROOM`

If the source/sample gate fails:

`DEFER_SOURCE_OR_SAMPLE`

A SURVIVE result authorizes only a separately frozen 10-second convergence sentinel on new/fresh evidence roles. It does not authorize PnL, Confirmation or promotion.

## Candidate 2 — Same-asset cross-venue causal flow propagation

### A. Mechanism identity

**Family:** venue-fragmented same-asset price discovery.

**Economic payer:** a market participant reacts first on one venue; a lagging venue incorporates the same information after a finite transport/liquidity delay.

**Causal trigger/state:** a prospectively fixed aggressive-flow/price impulse on a source venue, followed by the lagging venue's response.

**Nearest prior SC001 mechanisms:** C4 cross-asset BTC/ETH-to-alt lead/lag and C8B continuous cross-venue basis.

**Disposition:**  
`RELATED_BUT_MATERIALLY_DIFFERENT_ARCHITECTURE` only if the study is same-underlying, source-venue flow propagation with fixed causal leader semantics. A basis-threshold reversion or C4 lag-grid revival is not admissible.

This family is `ADAPTIVE_DISCOVERY_GENERATED`.

### B. Opportunity economics

- frequency: **many/day**;
- capital occupancy: 1-5 seconds;
- universe: broad liquid same-underlying cross-venue perpetuals;
- liquidity: high;
- USD 1,000 suitability: good from capacity perspective, poor if latency consumes the edge.

### C. Timescale

Mechanism timescale: 1-3 seconds.

Proposed primary horizon if later frozen: **2 seconds**.

Latency sensitivity: **very high**. The mechanism is rejected for the target user if meaningful response occurs before a public-cloud/user-scale action can be taken.

### D. Edge-to-Fill preflight

Two fills on the lagging venue.

The main structural concern is that ordinary SC001 conditional information is usually low-single-digit bps while a two-fill taker architecture can require materially more. Therefore this family is attractive only if an event-conditioned source impulse produces a much larger lagging response.

### E. Cheapest falsification test

Public trade tape only:
- fixed source venue and lagging venue chosen by pre-outcome structural/source criteria;
- one prospectively fixed impulse definition;
- one 2-second horizon;
- no L2 and no PnL.

Reject if the actionable signed lagging response is materially below the frozen two-fill headroom hurdle or if most response occurs before the first actionable second.

No threshold grid, leader swap, lag grid or winner-symbol selection is allowed.

### F. Data / implementation burden

Low:
- public trade tapes;
- strict causal synchronization;
- existing cross-venue semantic gate and coactive clock utilities.

No new collector should be built until a static/source feasibility card shows the required data already exist or can be obtained cheaply.

### G. Main risks

- leader/lagger relation may change by regime;
- common information can move both venues nearly simultaneously;
- latency can erase the mechanism;
- impulse-threshold selection creates severe multiplicity;
- apparent lead can be timestamp/source artifact.

**Portfolio disposition:**  
`RESERVE_CANDIDATE / DO_NOT RUN IN PARALLEL NOW`

Reason: cheap data burden, but high latency risk and high multiplicity if searched concurrently with Candidate 1.

## Candidate 3 — Liquidity replenishment / book-resiliency transition

### A. Mechanism identity

**Family:** recovery of displayed liquidity after a one-sided depletion shock.

**Economic payer:** temporary withdrawal/consumption of liquidity can displace price; subsequent replenishment by liquidity suppliers can restore local depth and reduce the displacement.

**Causal trigger/state:** a prospectively fixed side-specific depth-depletion transition relative to a causal local depth baseline, followed by a prospectively fixed replenishment state.

**Nearest prior SC001 mechanism:** C10 one-sided liquidity-vacuum onset / RB014-RB016.

**Disposition:**  
`RELATED_BUT_MATERIALLY_DIFFERENT_ARCHITECTURE` only if the core object is the replenishment transition and recovery anchor. Tail-selecting C10 or adding another filter to the old directional rule is `DISGUISED_RESCUE_REJECT`.

This family is `ADAPTIVE_DISCOVERY_GENERATED`.

### B. Opportunity economics

- frequency: many/day;
- capital occupancy: roughly 5-30 seconds;
- universe: broad liquid instruments with qualified L2;
- liquidity quality: state-dependent and weakest at the trigger;
- small-capital suitability: plausible if headroom exists.

### C. Timescale

Mechanism timescale: seconds to tens of seconds.

Proposed primary horizon if later frozen: **15 seconds**, tied to local book replenishment rather than a desire to enlarge bps.

Latency sensitivity: moderate.

### D. Edge-to-Fill preflight

Likely 2 fills. Maker assumptions must not be used to create feasibility before queue uncertainty is modeled.

Prior C10 evidence warns that frequent directional depth states can have inadequate standalone headroom. Therefore a new replenishment architecture must show structural movement scale before queue/fill simulation.

### E. Cheapest falsification test

Fresh L2, no PnL:
- prospectively fixed normalized depletion state;
- prospectively fixed replenishment/recovery definition;
- measure displacement present at depletion and remaining at the 15-second recovery anchor;
- reject if gross displacement/recovery scale is materially below the two-fill hurdle or depends on post-hoc rare-tail selection.

### F. Data / implementation burden

Higher than Candidates 1-2:
- qualified L2;
- causal local depth baseline;
- source-gap handling;
- later queue/execution uncertainty if the mechanism survives.

Existing RB014/RB015 measurement primitives are reusable, but fresh multi-asset L2 may be expensive.

### G. Main risks

- high disguised-C10-rescue risk;
- hidden liquidity and queue uncertainty;
- depth changes can be consequence rather than cause;
- adverse selection can dominate replenishment;
- much higher engineering/storage cost per decision.

**Portfolio disposition:**  
`HOLD_INFORMATION_VALUE / NOT NOW`
