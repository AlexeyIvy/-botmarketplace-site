# SC001 — B14-A P0 Collector v0.2 Post-Event Restart Guard Review v0.1

Date: 2026-09-19
Status: **ENGINEERING REVIEW / PRE-EVENT / NO OUTCOME CHANGE**

## Issue

The resilient v0.2 collector checks whether the capture window has already ended before consulting persisted COMPLETE state.

Under systemd this could cause a successful completed P0 collector to return a failure code after a later reboot and enter an unnecessary restart loop.

## Repair

v0.3 must:

1. load persisted state before the post-window guard;
2. if persisted state is `B14A_P0_COLLECTION_COMPLETE`, exit 0 immediately;
3. if the window ended without COMPLETE, persist/restate `B14A_P0_COLLECTION_REVIEW` and exit 0 as an operational terminal state;
4. keep the exact Sep25 event, T0, instruments, capture window, 50 bps hurdle and all research firewalls unchanged.

This repair occurs before the P0 price-capture event.
